# Hasil UI Tandur

59 gambar PNG dari seluruh route prototipe saat ekspor. Buka index.html untuk galeri. Semua gambar langsung berada di folder ini.

- Lebar desktop: 1440 piksel; tinggi mengikuti isi halaman penuh.
- Data ilustrasi disiapkan per halaman agar tahap persetujuan, akad, dan serah terima terlihat. Bukan transaksi nyata atau satu sesi berurutan.
- Route alias tetap diekspor, sehingga beberapa gambar menampilkan UI yang sama.
- manifest.json mencatat route, kode layar, nama file, dan ukuran.
- Sumber aplikasi tetap di ../prototipe/index.html. PNG adalah tampilan statis.
- Untuk ekspor ulang, jalankan prototipe/tests/export-ui.cjs dengan Node.js dan Playwright serta browser Edge tersedia.
